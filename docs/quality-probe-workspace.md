# 独立探针与本地判题

质量运维顶部按探针切换。每个探针只显示自己的账号、检测周期和运营记录；右键探针或点击齿轮打开配置，键盘方向键切换，Shift+F10 打开配置。独立账号规则单独归类。

## 检测周期和记录

- 状态探针、糖果题和 BPS 答题都可直接选择每几分钟检测；自定义周期仍支持五段 Cron。恢复探针保留检测间隔和正常后的复检间隔。
- 记录在服务端按探针、账号规则筛选后再聚合、分页；切换探针会清空旧记录和分页游标。
- 启用但零任务会显示“未生成任务”或“暂无可检测账号”。同步诊断区分不匹配、暂离范围、排除、不支持、等待同步和创建失败。查看诊断不会调用上游模型。
- 暂停不依赖上游模型列表查询，旧的慢更新不能重新启用已暂停任务；领取任务和提交处置时也会复核模板启停状态。

## 同账号多个探针

不同分组模板可以各自为同一账号建立计划，同模板同账号最多一条。主探针、恢复探针和答题探针不再争抢一个账号级名额。手动创建的独立规则保留原来的同类唯一限制。

迁移 `338_quality_template_identity.sql` 从已有绑定回填 `source_template_id`，不重建历史或处置快照。删除模板并选择保留任务时，任务和历史进入独立账号规则，原始来源仍保留；选择连任务删除时沿用原有处置校验。旧版本不了解新的模板身份约束，应用回退前需评估新增的同账号计划。
如果旧数据让多个模板共用同一条计划，迁移会明确报错并保留数据，要求先解决归属歧义。新索引禁止再次产生共享绑定。

“正常”筛选仍会排除限流、停调度账号；独立名额不会自动扩大既有筛选范围。`account` 通道沿账号现有路由，显式 `bps` 通道仍为仅观察；升级不会根据规则名称猜测或更改通道。

## 直接比对答案

新建答题规则默认使用“直接比对答案”，只需题目和预期答案。服务端给被测请求附加“只输出最终答案”的格式要求，参考答案不会发送给被测模型，也不再请求额外的判题模型。

- 数字按精确数值比较，`21`、`21.0`、全角数字及等价科学计数法一致；允许外层空白和完整代码块。
- 文本按约定输出 JSON 字符串，结构化答案输出完整 JSON。数值以外不做语义推断；需要语义判题时仍可选模型判题。
- 完整、明确的不同答案判错；解释长文、格式不明、缺字段、请求失败或截断记为无法判断，不据此执行答错处置。
- 旧模型判题、Jev 和未配置判题器的历史规则保留原语义。编辑已有规则时可切换为直接比对，保存后生效。

API 配置为 `pelican_config.quality.judge: {"kind":"exact"}`，无需分组、模型或判题提示词。检测结果保留 `quality_judgment.kind=exact` 与判定原因。
